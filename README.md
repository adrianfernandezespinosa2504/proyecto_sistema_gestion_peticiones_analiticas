# 🧪👨🏽‍🔬Sistema de gestión de peticiones analíticas – Sistema Sanitario de Aragón

## 
Proyecto académico centrado en el análisis, diseño y planificación del desarrollo de un sistema software para la gestión de peticiones de pruebas analíticas en el Sistema Sanitario de Aragón.

La propuesta plantea desarrollar una solución centralizada que permita integrar las aplicaciones clínicas utilizadas por los profesionales sanitarios con los distintos Sistemas de Información de Laboratorio (LIS), independientemente de las tecnologías empleadas por cada laboratorio.

El objetivo principal es mejorar la interoperabilidad entre centros sanitarios y laboratorios, optimizar la gestión de citas y extracciones y facilitar el seguimiento de las solicitudes y sus resultados.

## 🎯 Objetivos

- Integrar las aplicaciones clínicas con los diferentes Sistemas de Información de Laboratorio.
- Centralizar la gestión de peticiones de pruebas analíticas.
- Mejorar la coordinación entre centros sanitarios y laboratorios.
- Facilitar la consulta de peticiones y la gestión de extracciones.
- Permitir la impresión de etiquetas para la identificación de muestras.
- Optimizar la asignación de citas y reducir los tiempos de espera.
- Garantizar la privacidad y seguridad de la información sanitaria.

## ⚙️ Funcionalidades principales

La solución propuesta contempla los siguientes módulos:

- **Gestión de peticiones analíticas:** comunicación y seguimiento de las solicitudes realizadas desde las aplicaciones clínicas.
- **Gestión de citas:** organización de las citas de extracción y distribución de pacientes entre centros y franjas horarias.
- **Gestión de centros de extracción:** administración de centros, horarios y disponibilidad.
- **Gestión de laboratorios:** configuración e integración de los diferentes sistemas LIS.
- **Gestión de extracciones:** consulta de peticiones pendientes, identificación de contenedores mediante etiquetas y registro de extracciones e incidencias.
- **Consulta de resultados:** recepción y disponibilidad de los resultados de las pruebas analíticas.

## 🏗️ Arquitectura e integración

Se plantea una arquitectura centralizada que actúa como intermediaria entre las aplicaciones clínicas y los sistemas de laboratorio.

**Sistemas implicados:**

- **SGP:** Sistema Gestor de Pacientes.
- **OMI-AP:** Organizador Médico Informático para Atención Primaria.
- **LIS:** Sistemas de Información de Laboratorios de los distintos sectores sanitarios de Aragón.
- **Sistema integrador:** aplicación central encargada de coordinar las comunicaciones y gestionar las peticiones analíticas.

**Tecnologías y estándares contemplados:**

- Java / J2EE
- Oracle Database 10g
- Oracle Application Server 10g
- Rhapsody (plataforma de integración)
- HL7
- Servicios web SOAP/HTTP

## 📅 Planificación del proyecto

La planificación contempla una duración total de **105 días naturales**, desde el 1 de febrero hasta el 16 de mayo de 2027.

Las principales fases de trabajo son:

1. Identificación de las partes interesadas.
2. Análisis y especificación de requisitos.
3. Diseño de la arquitectura y los componentes.
4. Desarrollo y compilación del software.
5. Integración de los sistemas externos.
6. Elaboración de documentación técnica y manuales.
7. Pruebas funcionales, de integración, seguridad y rendimiento.
8. Implantación, validación y cierre del proyecto.

Se utiliza una planificación basada en actividades, dependencias, hitos y diagramas de Gantt, complementada con una organización del seguimiento mediante Sprints.

## 👥 Organización del proyecto

Se define un equipo multidisciplinar organizado en cuatro áreas funcionales:

- Análisis y diseño.
- Desarrollo e integración.
- Calidad y seguridad.
- Implantación, documentación y formación.

También se establece una matriz de responsabilidades RACI para definir la participación de los distintos perfiles profesionales en cada entregable.

## 💰 Presupuesto

Se realiza una estimación económica mediante el método *Bottom-Up* (de abajo hacia arriba), considerando:

- Recursos humanos.
- Equipamiento informático.
- Licencias de software.
- Desplazamientos y estancias.
- Costes internos y otros gastos.

**Presupuesto total estimado: 357.881,43 € (IVA incluido).**

## ⚠️ Gestión de riesgos

Se identifican y evalúan los principales riesgos que pueden afectar al proyecto, especialmente los relacionados con:

- Integración de sistemas sanitarios heterogéneos.
- Disponibilidad de recursos humanos y tecnológicos.
- Cumplimiento de los plazos establecidos.
- Seguridad y protección de datos sanitarios.
- Desviaciones presupuestarias.

Se establecen medidas preventivas y de seguimiento para minimizar su impacto.
